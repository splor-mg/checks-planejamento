# Verifica cada programa possui pelo menos um ODS

Com exceção do programa 705, todos os demais devem possuir um ou mais
Objetivos de Desenvolvimento Sustentável (ODS)

## Usage

``` r
check_ods_exists(
  programas_planejamento,
  output = FALSE,
  stop_on_failure = FALSE,
  json_outfile = NULL,
  log_level = "ERROR",
  msg_template = NULL
)
```

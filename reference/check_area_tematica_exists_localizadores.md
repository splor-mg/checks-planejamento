# Verifica se cada programa possui apenas uma área temática - localizadores_todos_planejamento

É obrigatório a existência de uma área por programa (ie. *one and only
one*).

## Usage

``` r
check_area_tematica_exists_localizadores(
  localizadores_todos_planejamento,
  stop_on_failure = FALSE,
  output = FALSE,
  json_outfile = NULL,
  log_level = "ERROR",
  msg_template = NULL
)
```

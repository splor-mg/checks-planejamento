# Verificar quantidade de programas incluídos entre as bases

Confere se o parâmetro is_new está idêntico entre as bases.

## Usage

``` r
check_count_programas_is_new(
  programas_planejamento,
  acoes_planejamento,
  output = FALSE,
  stop_on_failure = FALSE,
  json_outfile = NULL,
  log_level = "ERROR",
  msg_template = NULL
)
```

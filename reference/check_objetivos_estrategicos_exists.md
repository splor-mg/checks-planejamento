# Verifica se cada programa possui pelo menos um objetivo estratégico

Verifica se cada programa possui pelo menos um objetivo estratégico

## Usage

``` r
check_objetivos_estrategicos_exists(
  programas_planejamento,
  output = FALSE,
  stop_on_failure = FALSE,
  json_outfile = NULL,
  log_level = "ERROR",
  msg_template = NULL
)
```
